# 需求实施计划

- [ ] 1. 建立“基础数据到成品通报 Excel”的领域模型和接口边界
  - 以 R1（上传基础数据并识别结构）、R2（选择或创建专属工作流）、R3（生成通报表工作簿）、R4（输出可追溯成品）为边界，定义数据导入、工作流匹配、生成批次、通报配置和结果文件的数据结构。
  - 扩展现有 `DataSource`、`WorkflowDef`、`TaskRecord` 模型，增加数据摘要、适用字段签名、通报配置、生成批次标识、示例/用户来源和审计字段。
  - 新增生成批次、通报配置、工作流匹配记录和操作审计所需的 ORM 模型、迁移字段、关联关系和 API schema。
  - 保持 SQLite 单机架构、旧数据库自动迁移和现有模式 A/模式 B 数据兼容。
  - 为新模型编写数据库初始化、旧数据迁移和重复启动幂等测试。

- [ ] 2. 实现基础数据导入、识别和工作流匹配
  - 实现 CSV/XLSX 上传后的字段、类型、行数、空值、日期范围和数据指纹识别，对应 R1.1-R1.5。
  - 建立基于字段集合、字段类型、模板适配范围和用户选择的工作流匹配评分服务，返回推荐工作流、匹配原因、缺失字段和冲突字段。
  - 支持用户确认推荐工作流、切换其他适用工作流和创建当前基础数据专属工作流，对应 R2.1-R2.4。
  - 在导入后生成数据质量预检结果，并阻止关键字段缺失的数据直接进入生成流程。
  - 编写字段签名、类型兼容、缺失字段和多候选工作流排序的单元测试及属性测试：任意数据源字段顺序变化不得改变匹配结果。

- [ ] 3. 实现基础数据专属工作流创建向导
  - 将现有模式 A 映射和模式 B DAG 编辑器统一接入“基于当前数据创建工作流”入口，对应 R2.3。
  - 根据已识别字段和模板表头自动生成初始映射，标记精确匹配、模糊匹配和未匹配字段。
  - 支持用户选择模板版本、工作流模式、数据源字段映射、公式列策略、条件过滤和输出 Sheet 策略。
  - 保存工作流适用字段签名、模板版本、默认数据源规则和配置快照，后续导入相同结构数据时可自动推荐。
  - 编写向导保存、映射缺失、模板版本变化和 DAG 配置校验测试。

- [ ] 4. 实现通报表配置和通报业务输出
  - 建立通报配置表单和服务，支持通报标题、统计周期、发布单位、数据截止日期、落款、备注和输出文件名模板，对应 R3.1-R3.3。
  - 在模式 A 和模式 B 生成链路中统一执行字段映射、公式计算、条件过滤、聚合统计和通报表生成。
  - 支持通报表明细、汇总、异常数据、质量报告、基础数据和工作流配置等标准 Sheet，并允许按配置启用或隐藏 Sheet。
  - 保留模板样式、公式、Sheet 顺序、冻结窗格、列宽、筛选和格式，确保通报表可直接打印和继续编辑。
  - 编写通报配置默认值、标题落款、Sheet 生成顺序、公式结果和空结果集处理测试。

- [ ] 5. 实现成品 Excel 打包和可追溯结果管理
  - [x] 5.1 扩展任务生成器，将通报表、基础数据副本、工作流配置快照、模板版本信息和数据质量报告写入同一个成品 Excel，对应 R4.1-R4.4。
    - 已接入模式 A、模式 B 的统一生成链路，并保留原模板 Sheet 和公式。
    - 已新增 `通报表`、`基础数据`、`工作流配置`、`数据质量报告` 四类结果 Sheet。
  - [x] 5.2 在“工作流配置”Sheet 中写入节点、映射、公式、条件、模板版本、数据源摘要和生成时间，确保结果可复核。
    - 已写入工作流模式、模板版本、数据源信息、字段映射、节点 JSON 和生成数据行数。
  - [x] 5.3 增加成品预览 API，支持按 Sheet 预览和生成摘要。
    - 新增 `GET /api/tasks/{task_id}/final-preview`，默认返回每个 Sheet 前 20 行。
    - 任务历史增加“成品预览”弹窗，可切换查看全部成品 Sheet。
  - 增加单文件下载、批量 ZIP 下载、失败任务日志和按生成批次重新生成接口。
  - [x] 5.4 增加通报配置和生成批次快照。
    - 任务支持标题、统计周期、发布单位、数据截止日期、落款和备注。
    - 配置 JSON 写入任务记录和 `工作流配置` Sheet，批量任务共享 `batch_id`，重试任务继承配置。
  - [x] 5.5 增加生成批次摘要接口和任务历史聚合展示。
    - 新增 `GET /api/tasks/batches` 和 `GET /api/tasks/batches/{batch_id}`。
    - 批次摘要返回统一配置、任务总数、成功数、失败数、执行中数量和结果列表。
  - [x] 5.6 增加按批次重试失败任务。
    - 新增 `POST /api/tasks/batches/{batch_id}/retry`，重试任务继承数据源、工作流、通报配置和批次 ID。
    - 任务历史支持按批次重新提交失败任务。
  - 编写成品工作簿 Sheet 完整性、内容一致性、重复生成和批量打包测试。

- [ ] 6. 建立工作流中心和模板中心的可用操作流程
  - 在模板中心增加“适用数据字段”“推荐工作流”“示例教程”“创建专属工作流”和“选择模板版本”入口，对应 R2.1-R2.4。
  - 在工作流中心增加按数据结构、模式、模板版本、示例标识和最近使用时间筛选，并显示匹配适用范围。
  - 在任务执行页改造成“上传数据 -> 选择/创建工作流 -> 质量预检 -> 配置通报 -> 生成成品”的分步向导。
  - 在生成结果页增加成品 Sheet 导航、通报预览、配置快照、质量报告和下载入口。
  - 编写前端状态切换、上传失败、无匹配工作流、取消向导、刷新恢复和示例工作流复制测试。

- [ ] 7. 实现权限、审计和生成历史
  - 增加本地用户/角色模型和最小权限校验，区分工作流查看、编辑、运行、模板管理和结果下载权限，对应补充需求 P1。
  - 记录数据导入、工作流创建/修改/复制、模板版本切换、通报生成、下载和失败操作，对应补充需求 P2。
  - 在生成批次中保存输入数据指纹、工作流版本、模板版本、通报配置、执行时间、执行人和输出文件哈希。
  - 增加审计查询 API、生成批次详情 API和审计记录保留策略，避免记录敏感数据原文。
  - 编写权限拒绝、审计完整性、批次追溯和异常中断记录测试。

- [ ] 8. 实现批量基础数据处理和多成品输出
  - 支持一次上传或选择多份基础数据，按字段签名自动匹配工作流，对应补充需求 B1。
  - 支持批量任务逐项质量预检、逐项生成、逐项失败隔离和批次级进度汇总。
  - 支持每份数据生成独立通报 Excel，并额外生成批次汇总工作簿和 ZIP 包，对应补充需求 B2-B3。
  - 在结果页展示每个数据集的匹配工作流、质量状态、生成状态、输出文件和失败原因。
  - 编写多数据源混合成功/失败、工作流匹配差异、批次重试和 ZIP 内容完整性测试。
